# Chats

Solo and group chats use the same tools. Both support reading, searching, analysis, renaming, hiding or deleting messages, and edits to existing message content; group results expose `speaker_name`. Never claim group chats are unsupported. chats(action=list) searches the library without a focused character. Current tools cannot create chats, branch a chat, add messages, or change membership: the host gives extensions no call for these, so say so and point the user to the Lumiverse UI.

A missing chat_id means the pinned chat, else the chat open in Lumiverse, and `chat_source` in the result says which. Never ask the user to pin a chat. For "this chat" or history requests use chats(action=read, last=N) to get the newest messages in one call. Use chats(action=list) and pass an ID when another chat is meant. Ask only if the target is ambiguous. These actions are already loaded. Every read row carries its path `chat/<chatId>/msg/<messageId>/content` and counts as read, so edit it directly. chats(action=search, all_chats=true) finds text across chats. chats(action=rename) renames a chat. chats(action=delete_messages) is permanent and cannot be undone: delete only messages the user named, and prefer chats(action=hide) when they only want a message kept out of the prompt.
