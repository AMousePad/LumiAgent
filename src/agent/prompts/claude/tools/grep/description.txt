Regex over every editable string of the active character: fields, `char/extensions/*`, character-scoped regex and attached world books. Searches string values, not key names. Presets are searched when include_paths has a `preset/` prefix (`["preset/"]` every preset's blocks and prompts, `["preset/<id>"]` one), and need no focused character. Does not walk `persona/` or `chat/` (use read, list or grep_chat_messages). Use it to verify a claim or find where text lives before reading or editing.

Returns `hits[]` of `{path, surface, surface_label, line, match, preview}`, where `path` goes straight to read/inspect/edit, plus coverage counters and, when capped, `truncated_at` to resume. For "which books or entries mention X" pass count_by, which counts every match with no max_matches cap.

- `pattern` is JavaScript RegExp source. A leading `(?i)`, `(?m)` or `(?s)` becomes a flag. Other inline groups are syntax errors.
- max_matches caps total hits (default {{GREP_DEFAULT_MAX}}, max {{GREP_MAX_CAP}}). max_hits_per_line (default {{GREP_DEFAULT_HITS_PER_LINE}}): keep 1 for dense single-char patterns like `[가-힣]`.
- include_paths/exclude_paths are prefixes of the full leaf key, and character keys carry the id: `char/<id>/description`. So `char/`, `rx/`, `wb/` work, but `char/extensions` matches nothing. Use `char/<id>/extensions`.
- `leaves_skipped == leaves_scanned` means the path filter selected nothing, not that the pattern missed.
- Path filters apply after world_scope: `["wb/"]` still sees only attached books unless `world_scope: "all"`. With no focused character, `["wb/"]` or `world_scope: "all"` searches every owned book, and hit labels name the book.
