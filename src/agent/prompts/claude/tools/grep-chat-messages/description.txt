Regex search chat messages. With no scope it searches one chat and returns matched message ids, paths, speakers, lines, and previews. chat_id is optional: omitted means the pinned chat, else the chat open in Lumiverse. `all_chats: true` searches the 60 most recently updated chats, `character_id` searches every chat containing that character: both return per-chat match counts with a few previews, so follow up with chat_id for one chat's full hits. Only the active swipe of each message is searched.
