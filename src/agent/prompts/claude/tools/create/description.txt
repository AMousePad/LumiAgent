Create an entity inside a container. The path names the PARENT (same grammar as read/set) and `value` holds the new entity's fields. Revertable: revert deletes it.

- `wb` -> world book. value: { name, description?, metadata? }
- `wb/<bookId>/entry` -> entry. value: { content (required), key?, keysecondary?, comment?, constant?, disabled?, position?, depth?, order_value?, probability?, ... any other entry setting }
- `rx` -> regex script for the active character. value: { name, find_regex, replace_string?, flags?, placement?, target?, disabled?, description? }
- `persona` -> value: { name (required), title?, description?, folder?, is_default?, attached_world_book_id? }
- `preset` -> value: { name (required), provider (required), engine?, parameters?, prompts?, metadata? }
- `preset/<presetId>/block` -> value: block fields { name?, content?, role?, enabled?, position?, depth?, ... } plus optional `index`.
- `char/alternate_greetings` -> a string, or { content, index? }.
- `char/alternate_fields/<field>` -> description/personality/scenario variant. value: { content (required), label?, index? } or a bare string.

Returns the new id, plus the book/preset id for nested creates.
