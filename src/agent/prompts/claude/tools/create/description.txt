Create an entity inside a container. The path names the PARENT (same grammar as read/set) and `value` holds the new entity's fields. Revertable: revert deletes it.

- `wb` -> world book. value: { name, description?, metadata?, entries?: [ {content, key?, ...}, ... ], attach?: "character" | "chat" | "global" | "persona" } creates the book, its entries and its attachment in one call. Duplicate with value { copy_of: "<book id or name>", name }: every entry and every setting is copied. The result says where the book is attached, and an unattached book never fires.
- `wb/<bookId>/entry` -> entry. value: { content (required), key?, keysecondary?, comment?, constant?, disabled?, selective?, selective_logic?, position?, depth?, order_value?, probability?, ... any other entry setting }, or an array of them to create several in order. To copy or move, never re-type entries: value { copy_of: "<entryId>" or [ids] or "<bookId>" for all of its entries, ...overrides, move?: true } copies them into this book byte-for-byte, and move deletes the sources after the copy. position: 0 World Info Before slot, 1 After slot, 2/3 before/after author note, 4 at depth (uses depth), 5/6 before/after examples, 7 at marker, 8 outlet only. selective_logic (needs selective and secondary keys): 0 AND all, 1 NOT any, 2 OR any, 3 NOT all.
- `rx` -> regex script. value: { name, find_regex, replace_string?, flags?, placement?, target? (prompt|response|display), scope? (global|character|chat, default: focused character, else global), scope_id?, folder?, sort_order?, disabled?, description?, substitute_macros?, preset_id? (deleted together with that preset. It does NOT make the script follow the preset selection: a script created here runs under every preset while enabled) }. To duplicate, never re-type patterns: value { copy_of: "<scriptId>" or [ids] } copies scripts byte-for-byte, value { copy_folder: "<folder name>", folder: "<new folder>" } copies a whole folder in one call. Any other field given alongside overrides the copies (scope, folder, target, disabled, preset_id).
- `persona` -> value: { name (required), title?, description?, folder?, is_default?, attached_world_book_id?, metadata? }. Duplicate with value { copy_of: "<persona id or name>", name }: text, folder, lorebook and add-ons are copied. The portrait and pronouns cannot be copied, the result says so.
- `persona/<personaId>/addon` -> a persona add-on text block. value: { content (required), label?, enabled?, outlet_name? } or a bare string.
- `char` -> duplicate a character with value { copy_of: "<character id or name>", name }: one call copies every field, greeting, tag, lorebook link, extension, the portrait and the character's regex scripts. Other fields given alongside override the copy. A card from scratch is create_character.
- `preset` -> duplicate with value { copy_of: "<preset id or name>", name: "<new name>" }: one call copies every block, sampler setting, prompt and variable value. A blank preset takes { name, provider: "loom", description? }.
- `preset/<presetId>/block` -> value: block fields { name?, content?, role?, enabled?, depth?, ... }. Placement in the list: `after` or `before` (a block name or id), or `index`. Default is the end. To copy blocks, also across presets, never re-type them: value { copy_of: "preset/<srcPresetId>/block/<blockId>" or [paths], after? } copies content, settings, variables and their values.
- `char/alternate_greetings` -> a string, an array of strings (several greetings in one call), or { content, index? }. `char/<id>/alternate_greetings` or `character_id` targets a non-focused character, and the result names the character written.
- `char/alternate_fields/<field>` -> description/personality/scenario variant. value: { content (required), label?, index? } or a bare string.

Results report what landed (ids, names, settings, counts) and any ignored field, so no follow-up check is needed.
