Find/replace inside a string leaf, by path (same grammar as read, e.g. char/first_mes, rx/<id>/replace_string, wb/<id>/comment).

1. Read first: `read` on the same path, or a `grep` hit on it, within 60 minutes, byte-exact key (char/description does not open char/extensions/...). One read covers any number of consecutive edits. A `[STALE_READ]` means the leaf changed, so re-read.
2. `find` is a literal, not a regex, and must occur exactly once unless replace_all. Widen it only as far as uniqueness needs, and keep `replace` identical outside the span you mean to change.
3. On a miss, curly/fullwidth quotes are retried as ASCII (`recovered_via` says so). Other drift (NFC/NFD, NBSP, line endings, whitespace) is not: copy bytes from the read, or run inspect for encoding diagnostics.
4. A failed call stores the replacement as a draft, reusable via `replace_handle`.

Returns path, replacements, a snippet around the first hit and a diff patch for the UI.
