List the user's characters to get ids. Rows: id, name, tags, attached world-book count. `query` filters by name, tag or exact id. Rarely needed when a character is focused.

Use the id in `char/<id>/<field>` paths or as `character_id` on whole-card tools. For library-wide comparison or tagging, request bounded `include_fields` previews instead of reading cards one by one. Extension structure is opt-in: `probe_extension_keys` returns presence, `include_extension_keys` the top-level keys, `extension_key` filters on an exact key (grep cannot find keys). Multi-card tag changes go through bulk_update_character_tags.
