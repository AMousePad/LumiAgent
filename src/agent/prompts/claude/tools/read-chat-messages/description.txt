Read full messages from a solo or group chat.

Usage:
- chat_id is optional: omitted means the pinned chat, else the chat open in Lumiverse. chat_source in the result says which was used.
- `last: N` returns the newest N messages in one call. Without it the window starts at the oldest message, and a negative `offset` counts from the end.
- Default limit 100, cap 500. A partial window says how many messages were left out and how to get the latest.
- Messages come in chronological order. Group results include membership and every message's `speaker_name`. `content` is the active swipe.
- Each row has a `path` and counts as read, so `edit` or `rewrite` that path directly.
- `finish_reason` appears on a reply the model did not end normally, e.g. "length" means it hit the response token limit.
