Store or clear a value referenced as `{{lumiagent::<name>}}` anywhere Lumiverse resolves macros (presets, world book entries, author's notes, greetings). Bare `{{lumiagent}}` lists stored names. Values persist across sessions and are per-user, not per-chat, so one reference resolves the same in every story. For per-chat state use set_variable.

Storing changes nothing until something references it, so tell the user the exact string to paste. Names: `a-z0-9_`, max 64 chars, max 100 stored. Values: max 8000 chars of plain text, macros inside are not re-expanded. `clear: true` deletes.
