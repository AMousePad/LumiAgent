List a container's children. Paths: char, char/alternate_greetings, char/alternate_fields[/<field>], char/extensions[/<dotted-with-brackets>], rx, wb[/<bookId>], persona, preset[/<presetId>], preset/<presetId>/var. Page with next_offset until has_more is false. max_depth (default 4) applies to extension trees only, scope large ones to a subtree.

rx lists the focused character's regex scripts (the global ones when no character is focused) and reports how many global scripts exist. With query it searches character and global scripts together by script name, folder name or bound preset name, so list({path:"rx", query:"<folder or preset>"}) returns that whole set. rx rows add scope, target and folder. character_id overrides focus for char/rx/wb. list does not parse char/<id>/...: pass path="char/extensions" with character_id. Returned char/ paths are unqualified, so insert char/<id>/ to address another character. Persona, preset and wb/<bookId> need no focus. wb lists the books attached to the focused character and reports how many other books exist, or the whole library when no character is focused. list({path:"wb", query:"<name>"}) searches every owned book by name regardless of focus, attached ones first. wb rows carry attached (with a focused character) and global. An unknown id in wb/<id> is an error that says where to look.

Rows carry path, type, label and size (string chars, or child count for containers, entries for world_book). wb_entry rows add keys and secondary_keys plus every non-default setting (constant, disabled, position, depth at position 4, order_value, selective, selective_logic, group_name, role, probability, vectorized), so one list answers "which keywords" and "how is it configured". query on wb/<bookId> matches the title, keys and secondary keys. preset lists every preset and reports which one is selected and which one the pinned chat uses. preset/<id> rows are in prompt order with index, enabled (toggle with set .../enabled), and variables when the block carries settings; preset_category rows are section headers. preset/<id>/var lists the preset's settings variables with label, type, options and current value, which is the only place those values are readable. preset_prompt rows are readable leaves. Other rows need a leaf appended before read: rx/<id>/find_regex|replace_string, wb/<entryId>/content|comment, preset/<id>/block/<blockId>/content|name, alternate_fields/<field>/<variantId>/content|label. An extension count of 0 can mean empty, scalar or hidden: inspect tells them apart.
