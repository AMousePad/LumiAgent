List a container's children. Paths: char, char/alternate_greetings, char/alternate_fields[/<field>], char/extensions[/<dotted-with-brackets>], rx, wb[/<bookId>], persona, preset[/<presetId>]. max_entries defaults to 200 (max 2000), max_depth to 4 (max 10, extension trees only). Scope large extension trees to a subtree.

For char/rx/wb, character_id overrides focus. list does not parse char/<id>/...: use path="char/extensions", character_id="<id>". Returned char/ paths are unqualified: insert char/<id>/ before reading or writing another character. rx/wb IDs already identify their owners. Persona/preset and wb/<bookId> need no focus. include_unattached=true on wb lists the whole library.

Rows contain path, type, label and size. String size is characters, container size is child count, world_book.entries counts entries. Read only string rows or char/tags directly. For other rows, append a leaf: rx/<id>/find_regex or replace_string, wb/<entryId>/content or comment, preset/<id>/block/<blockId>/content or name, alternate_fields/<field>/<variantId>/content or label. Extension count=0 can mean empty, scalar or hidden content. Use inspect to distinguish strings from non-string values.
