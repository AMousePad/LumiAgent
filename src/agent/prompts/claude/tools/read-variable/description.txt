Read one variable by name. With no scope it looks in every store of the chat and says where the key was found: `chat` ({{getchatvar}}, Risu / LumiRealm getvar), `global` ({{getgvar}}), `local` and the legacy user-level store. With a scope it reads that store and still reports the key if it only exists elsewhere. Returns { exists, scope, value, store, read_by }. chat_id is optional: omitted means the pinned chat, else the chat open in Lumiverse.
