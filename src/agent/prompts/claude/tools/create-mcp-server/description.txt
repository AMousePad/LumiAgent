Create a persistent MCP server profile in Lumiverse using a user-supplied HTTP/SSE endpoint or stdio command. Requires mcp_servers.create permission. HTTP transports require url, stdio requires command. Lumiverse enforces its network and executable policies. auto_connect defaults to false, and creation does not connect immediately. Reuse an existing profile when appropriate. Stored credentials cannot be read back through MCP profile discovery. Tool arguments remain visible in the conversation, so direct the user to Settings > MCP Servers to enter credentials privately. MCP profiles and remote changes are not covered by LumiAgent's edit undo. No focused character needed.
