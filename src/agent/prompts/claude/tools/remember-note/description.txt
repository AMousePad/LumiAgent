Append a durable note to your own notes file (agent/agent.md), which is loaded into the system prompt of every future session. Use it for facts you would otherwise rediscover: the user's stated preferences, naming conventions, which card belongs to which project, decisions made in this session. One fact per call, present tense, under 300 characters. Not for task progress (use todo_write) or chat memory (use remember_fact). The current session keeps its frozen snapshot; the note appears from the next session on.
