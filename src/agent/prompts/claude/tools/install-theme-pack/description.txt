Install CSS and an optional native theme configuration through backend theme authoring. Read get_theme or inspect_theme state first and pass expected_revision when applying. Persistent changes continue without a connected browser.

Default mode=merge preserves omitted global CSS, components and assets. mode=replace deliberately replaces styling. Applied changes create a complete backup in My Themes, including existing TSX and assets. Use theme_archive restore with its backup_id and a fresh revision to undo. save_to_library also saves the authored result as a named pack.

Component CSS is full rules, never bare declarations or automatically scoped. Obtain root selectors or build-specific CSS-module classSelectors from inspect_theme when references are available. CSS syntax errors and malformed component IDs reject installation. A valid ID does not establish that a component is mounted. Removed external imports/URLs and unsupported declarations produce warnings. Use theme_assets for portable imagery and fonts. Normal root variable rules lose to generated inline variables, so prefer the native theme configuration.

For workspace JSON drafts, validation without applying, component removal, and disabled global CSS use edit_theme. TSX installation requires review in the native editor. Switching a base preset does not clear custom CSS. Safe-theme mode suppresses styling for recovery but does not restore overwritten edits.
