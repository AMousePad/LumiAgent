Append a durable fact to a memory entity. The last 6 facts render into every later generation's entity context, verbatim from the next message on.

The entity resolves by name or alias and is created with `entity_type` (default character) if missing. The list caps at 30 and evicts lowest `importance` first (1-10, default 5, ties keep the newer), so use 8-10 for facts that must stay. Dedup is case-insensitive. Keep facts to one present-tense clause. Defaults to the pinned chat.
