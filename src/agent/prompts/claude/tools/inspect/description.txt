Inspect a string leaf's character/line/CJK counts, preview and encoding diagnostics before editing. Diagnostics identify Hangul normalization, invisible characters, line endings, smart quotes and divergent LumiRealm mirrors.

Containers: rx summarizes character regex scripts, rx/<id> reports one script, wb lists all world books, wb/<bookId> summarizes entries, preset lists presets, preset/<id> lists blocks. Optional character_id scopes rx/wb discovery. Other paths must resolve to strings: use list to walk objects and arrays, read for full text, set to replace a JSON subtree. Leaf paths follow read's grammar, including explicit char/<id>/<field> targeting. Inspection does not satisfy edit's recent-read requirement.
