Inspect a string leaf's character/line/CJK counts, preview and encoding diagnostics before editing. Diagnostics identify Hangul normalization, invisible characters, line endings, smart quotes and divergent LumiRealm mirrors.

Containers: rx summarizes regex scripts (focused character plus global) with a per-folder breakdown, rx/<id> reports one script including scope, target, folder and preset_id, wb lists all world books, wb/<bookId> (id or name) summarizes a book with its description, metadata and attached_to (global, characters, personas), wb/<entryId> returns every setting of one entry in one call with its book and a content peek, preset lists presets and the active one, preset/<id> summarizes one preset (block and variable counts, categories, sampler values, whether it is selected), preset/<id>/var lists its settings variables. Optional character_id scopes rx/wb discovery. Other paths must resolve to strings: use list to walk objects and arrays, read for full text, set to replace a JSON subtree. Leaf paths follow read's grammar, including explicit char/<id>/<field> targeting. Inspection does not satisfy edit's recent-read requirement.
