Write any JSON value at a path, for changes edit/rewrite can't make. Unknown field names error with the valid list. Revertable like every edit.

- Lorebook entry settings: `wb/<entryId>/constant` true, likewise disabled, priority, position, depth, role. `key`/`keysecondary` take the full string array (a comma string is split).
- Book fields: `wb/<bookId>/<name|description|metadata>`.
- Regex settings: `rx/<scriptId>/disabled` true, likewise sort_order, target, placement, flags, name.
- Preset block settings: `preset/<presetId>/block/<blockId>/enabled` false. Block content/name text uses edit/rewrite.
- Character tags: `char/tags` ["a","b"] (trimmed, deduped). For many characters use bulk_update_character_tags.
- Extension values: arrays, objects or typed scalars at `char/extensions/<dotted>`.
- Persona lorebook: `persona/<personaId>/attached_world_book_id` "<bookId>", null detaches. Character, chat and global bindings use attach_world_book.

Path grammar matches read. `char/<id>/...` or `character_id` targets a non-focused character. On a string leaf, set replaces the whole text without the read gate. Prefer rewrite when the current text matters. For several character fields at once use update_character.

Returns path, before_chars, after_chars and 120-char before_peek/after_peek. Check after_peek, since stored values can be normalized.
