Set or delete a variable that Lumiverse macros read. The write half of `list_variables` / `read_variable`.

Scopes, both stored on one chat:
- `chat`: `chat.metadata.chat_variables`, read by `{{getchatvar}}` and by Risu / LumiRealm `getvar`. Card triggers write the same store and can overwrite your value when they fire.
- `global`: `chat.metadata.macro_variables.global`, read by `{{getgvar}}` / `{{getglobalvar}}`. Despite the name Lumiverse keeps these per chat, so set it in each chat that needs it.

`{{getvar}}` values are not stored anywhere: Lumiverse rebuilds them for every prompt from the active preset's variables. To change one, `set` `preset/<presetId>/var/<name>`.

Values are strings, send numbers and booleans in string form. `clear: true` deletes the key. chat_id is optional: omitted means the pinned chat, else the chat open in Lumiverse. The result names the store and chat written and returns the previous value. Changes are recorded in Workshop and can be reverted there.

LumiRealm module toggles live in a separate per-user store: use `set_toggle`. For card-side defaults edit `scriptstate_defaults`. For agent-maintained prompt text the user pastes a reference to (summaries, directives), prefer `set_macro`'s `{{lumiagent::name}}`: it is namespaced to the agent and cannot collide with card macros.
