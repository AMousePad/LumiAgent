List a chat's variables. With no scope it returns every store at once, each with the macros that read it: `chat` (chat.metadata.chat_variables, read by {{getchatvar}} and written by Risu / LumiRealm setvar), `global` (chat.metadata.macro_variables.global, read by {{getgvar}} / {{getglobalvar}}), and `local` (chat.metadata.macro_variables.local, which no macro reads at generation time). chat_id is optional: omitted means the pinned chat, else the chat open in Lumiverse.
