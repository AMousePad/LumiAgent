Assemble a chat's exact prompt without calling a model. Pass chat_id or pin a chat first. Use chats(action=active/list) to find the intended chat. The active chat is not selected implicitly. Optional connection/persona/preset IDs override assembly context. Connection otherwise uses LumiAgent's selection. Returns messages, block breakdown, token count, parameters and world-info/memory statistics. Large output spills to tmp handles for tmp_read/tmp_grep.
