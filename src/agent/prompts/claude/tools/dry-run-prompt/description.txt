Assemble a chat's exact prompt without calling a model. Uses chat_id, else the pinned chat, else the chat open in Lumiverse. chat_source in the result says which one was used. Optional connection/persona/preset IDs override assembly context. Connection otherwise uses LumiAgent's selection. A given preset_id is forced over any chat, persona or character preset binding, and preset_id, preset_name and preset_source in the result say which preset the prompt was built with. Returns total_tokens, chat_history_tokens, context_clip (the context budget and how many old messages were dropped to fit it), sections_by_tokens (largest first, chat history included), a block breakdown with char sizes, parameters and world-info/memory statistics. Message bodies are omitted unless include_messages is true, and that output usually spills to a tmp handle for tmp_read/tmp_grep. Mode-specific preset prompts (new chat, continue, impersonate, group nudge) only appear when that mode applies. To find where a piece of prompt text comes from, grep with include_paths ["preset/"] first.
