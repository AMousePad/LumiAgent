Curate a memory entity: retire it from retrieval, mark it dead/destroyed in-fiction, revive it, merge duplicate names via aliases, or pin it against automatic drift.

- `status`: `inactive` removes it from retrieval and the prompt (the prune primitive; there is no hard delete). `deceased` / `destroyed` model in-fiction fate. `active` revives.
- `add_aliases`: alternate names that should resolve to THIS entity. The dedupe path for "Kae" / "the Ashen One" duplicates: alias the canonical entity, then retire the duplicate row.
- `pin: true` locks the entity: automatic extraction can no longer overwrite its name / type / aliases, and garbage collection can never delete it. Pin after curating so the sidecar does not drift your work. Pinning is permanent.

Resolved by `name` (aliases count) or `entity_id`. Defaults to the pinned chat. Cache is invalidated afterward.
