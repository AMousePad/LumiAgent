Resolve `{{macro}}` placeholders in arbitrary text using Lumiverse's macro engine. Always runs in non-committing dry mode (`commit: false`) so extension macro handlers don't side-effect. With a chat (chat_id, else the pinned chat) chat-scoped macros resolve and {{char}} binds to that chat's own character, even when another character is focused. With no chat {{char}} binds to the focused character. An explicit character_id always wins. Returns { text, diagnostics, chat_id, character_id }.
