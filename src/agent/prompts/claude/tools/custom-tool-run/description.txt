Run ordered tool calls as one pipeline, or execute a saved recipe by name. Supply exactly one of steps or name. Each step has sibling keys call, args, save_as. Unknown step keys are rejected before execution. Put every called tool argument inside args.

Use save_as:"body", then {{$body}} for its raw value, {{$body.field[0]}} for a nested value, or embedded references for strings. Returns explicit return if supplied, otherwise saved bindings, otherwise the final result. Save each write result you need to confirm.

Not atomic: each step validates and runs in order. On failure, earlier writes remain. Fix and resume at the failed step, never rerun completed mutations blindly. Limits: 400 steps, nesting depth 4, 60 seconds shared across nested calls. Use custom_tools to manage saved recipes. Load an unfamiliar tool's schema before using it in a pipeline.
