Create a new character card from a full spec: name (required) plus any of description, personality, scenario, first_mes, mes_example, creator_notes, system_prompt, post_history_instructions, creator, tags, alternate_greetings, world_book_ids, extensions.

Use for "spin up a character from this idea / this chat / this summary". Write real content into the fields at creation rather than creating an empty shell and editing it after; each post-creation edit is a separate call and a separate ledger entry.

To duplicate a card, never re-type it: pass `copy_of` (character id or name) with the new `name`. One call copies every text field, greeting, tag, lorebook link, extension, the portrait and the character's regex scripts, and the result lists what was and was not carried.

Returns `created.id`, the id for `char/<id>/<field>` addressing, plus what landed. The new card appears in the user's library immediately and is not focused. Workshop records creation as history. Remove an unwanted card with `delete({path:"char/<id>"})`.
