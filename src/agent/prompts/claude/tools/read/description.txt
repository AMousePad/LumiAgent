Read a string leaf as line-numbered text and satisfy edit's recent-read requirement. offset/limit paginate lines. Large results return spilled=true and tmp_handle, read or search that handle with tmp_read/tmp_grep. Use list for containers, not read.

Paths:
- char/<field>, char/tags, char/alternate_greetings/<index>, char/alternate_fields/<field>/<variantId>/<content|label>, char/extensions/<dotted-with-brackets>
- rx/<scriptId>/<find_regex|replace_string>
- wb/<entryId>/<content|comment>
- persona/<id>/<name|title|description>, persona/<id>/wb/<entryId>/<content|comment>, persona/<id>/addon/<addonId>/<content|label>
- global_addon/<id>/<content|label>
- chat/<chatId>/msg/<msgId>/content
- preset/<presetId>/block/<blockId>/<content|name>

char/<field> uses focus. Insert an explicit ID after char/ to address another character: char/<id>/extensions/<dotted>. read/edit/rewrite/set do not accept character_id arguments. Other path IDs identify the target directly. Discover IDs with list, list_characters, chats or personas. Extension objects/arrays are not strings: walk them with list or replace them with set. Tags are returned as a JSON string array.
