Discover tools advertised by one connected MCP server. Returns exact tool names, descriptions, and original input_schema objects, with optional substring filtering and pagination. Does not connect or call tools. Use connect_mcp_server first if disconnected. Invoke a discovered tool through call_mcp_tool, not as a standalone LumiAgent function. Read its input_schema before constructing arguments, including nested types and references. Large schemas spill to tmp storage and can be read with tmp_read. No focused character needed.
