Permanently delete messages from a chat. This cannot be undone: Lumiverse has no restore for deleted messages, and every swipe of a deleted message goes with it, so the user is always asked to confirm. Pass message_ids (from chats(action=messages) or chats(action=read)), or last_n to remove the newest N. Returns each deleted id with role and a short preview. The removed text is saved in the Workshop history for reference only. To take a message out of the prompt while keeping it, use chats(action=hide) instead.
